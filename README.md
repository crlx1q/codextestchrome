# UMA Browser

UMA — настольный браузер на Electron + TypeScript с Chromium под капотом. Проект задуман как качественная база для будущих тем, обоев, виджетов и расширений.

## Возможности

- Вкладки: создание, закрытие, закрепление, дубликат, восстановление закрытой вкладки.
- Адресная строка (omnibox): ввод URL, поиск через провайдера, подсказки по истории/закладкам/топ-сайтам.
- Навигация: Back / Forward / Reload / Stop, кнопка Home.
- Закладки: добавление/удаление, папки, панель закладок.
- История: логирование посещений, поиск, очистка.
- Загрузки: прогресс, пауза/возобновление, показать в папке.
- Настройки: тема, поисковый провайдер, стартовая страница, блокировка трекеров, панель закладок.
- Инкогнито-окно: отдельный in-memory partition.
- Контекстное меню: назад/вперед/перезагрузить, копировать/вставить, открыть ссылку в новой вкладке, сохранить изображение.
- Горячие клавиши: Ctrl+L, Ctrl+T, Ctrl+W, Ctrl+Shift+T, Ctrl+Tab, Ctrl+R, Ctrl+Shift+R, Ctrl+Plus/Minus/0, Ctrl+F.

## Архитектура

```
src/
  main/         # Electron main process (окна, вкладки, хранение, IPC, загрузки)
  renderer/     # UI оболочка браузера (React + Vite)
  shared/       # общие типы IPC и контракты
resources/      # иконки, блоклист
```

Ключевые слои:
- **Main process**: `TabManager` управляет `BrowserView`, история и загрузки сохраняются в lowdb, IPC валидируется по структуре.
- **Renderer process**: UI оболочка браузера (вкладки, omnibox, внутренние страницы `uma://*`).
- **Shared**: строгие типы IPC (`src/shared/ipc.ts`).
